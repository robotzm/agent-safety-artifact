Evaluation protocol

A place for reproducible evaluation details.

Protocol forthcoming. The sections below are an outline, not a description of completed experiments.

Task specification

Document the intended user goal, initial environment, available tools, safety constraints, and verifiable completion conditions for each task.

Evaluation setup

Specify agent and model versions, prompts, tool permissions, feedback settings, budgets, seeds, and environment reset procedures.

Metrics and scoring

Define the exact metrics, denominators, missing-run handling, scoring procedures, and any adjudication or uncertainty estimates before presenting results.

Reproducibility

Add installation requirements, evaluation commands, configuration files, and the version of the benchmark associated with each reported result.

Release status

The implementation, dataset, and verified results will be linked from the resource section when available.
