Repository layout

docs/       Static project website
src/        Benchmark implementation (forthcoming)
data/       Dataset and documentation (forthcoming)
configs/    Evaluation configurations (forthcoming)
results/    Verified evaluation outputs (forthcoming)
scripts/    Website link checker

Run the website locally

python3 -m http.server 8000 --directory docs

Open your browser at http://localhost:8000. No package installation or build step is needed.

Check local links

python3 scripts/check_links.py

Run this command from the repository root after changing pages or adding local resources.
